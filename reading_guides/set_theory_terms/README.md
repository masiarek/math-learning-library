# Set theory: the terms, and where each one lives

**Level:** reference · for the owner's list of 646 terms of set theory, from "set" to Berkeley cardinals, with the page or glossary entry that covers each one here, and the book that covers the rest

**One line:** Of the 646 terms, 261 have a home in this library and 385 do not; a term with a home is linked to it, a term without one is named under "not here yet" with the book that treats it, and no stub pages were made, because a page with no argument and no program is what the [roadmap](../../ROADMAP.md) rules out, and this list is where such a page would have pointed anyway.

The list is the owner's, sent in October 2026, grouped as they grouped it. A term counts as "here" when a lesson or a glossary entry explains it, not when a page merely mentions it; links to the glossary land on the entry. The book pointers for uncovered sections are from memory and name editions loosely; the [reading guide](../set_theory/README.md) has the verdicts on the books. Topics from this list that had an argument and a program became lessons in the same session: [Cantor–Schröder–Bernstein](../../04_Sets/schroeder_bernstein/README.md), [multisets](../../04_Sets/multisets/README.md), [Ramsey's theorem](../../04_Sets/ramsey/README.md), [two balls from one](../../13_Axioms_of_Set_Theory/two_balls_from_one/README.md), [the forms of choice](../../13_Axioms_of_Set_Theory/choice/README.md#the-equivalent-forms-and-the-weaker-ones), and the counting of partitions on [equivalence relations and partitions](../../04_Sets/equivalence_and_partitions/README.md). What remains uncovered and is worth a page is on the memory inbox: cardinal arithmetic, order types, filters on a finite set, trees with König's lemma, Cantor's back-and-forth on ℚ.
