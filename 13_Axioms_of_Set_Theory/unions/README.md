# Unions: the members of the members form a set

**Level:** 201 · for anyone reading ∀v₀∃v₁∀v₂(v₂ ∈ v₁ ⇔ ∃v₃(v₃ ∈ v₀ ∧ v₂ ∈ v₃)) and seeing no ∪ in it

**One line:** The axiom of unions does not mention a ∪ b; it gives ∪a, the set of everything that is a member of some member of a, from which a ∪ b is the special case ∪{a, b}; it never fails in a finite universe, because opening a set one level lowers its rank, and its mirror image, the intersection ∩a, is only safe when a is not empty.

## The axiom, read aloud

> ∀v₀ ∃v₁ ∀v₂ (v₂ ∈ v₁ ⇔ ∃v₃ (v₃ ∈ v₀ ∧ v₂ ∈ v₃))

For every set a there is a set b such that z is a member of b exactly when there is some set w with w a member of a and z a member of w. In words, **b collects the members of the members of a**: it opens every member of a one level and pours out what is inside. The book writes it ∪a, or ∪ₓ∈ₐ x, and calls it the union of the family a.

Notice what the formula does not say. There is no a ∪ b in it. The two-set union everyone knows is derived: a ∪ b = ∪{a, b}, the pair first, then the axiom, which is section 3 of the program and page 112 of the book. Writing the axiom for a whole family at once costs nothing extra and buys the union of infinitely many sets, which a ∪ b repeated could never reach.

## What it is for

**Everything finite.** {a, b, c} = {a, b} ∪ {c}, then {a, b, c, d}, and so on. With [pairs](../pairs/README.md), this axiom makes every finite set of sets you can write down.

**Everything infinite, in one step.** ∪ of a family of intervals, ∪ of the sets in a sequence, the union of all the sets a construction has produced so far: each is a single application. The successor n ∪ {n} of a von Neumann number, and ∪ of a set of ordinals, which Cori and Lascar prove is their least upper bound (Proposition 7.26), are unions of this kind, and section 1 shows ∪3 = 2, the union undoing a successor.

**Its mirror image needs care.** The intersection ∩a, the set of things in every member of a, is not an axiom but a consequence of [comprehension](../comprehension/README.md): pick one member c of a and keep those members of c that are in every member of a. That needs a member to pick. For a = ∅, "x is in every member of a" is true of every x, since there is no member to fail, so ∩∅ would be the set of all sets, which does not exist. Section 5 shows the vacuous truth in one line of Python. The book makes the same point at the top of page 115.

## Why it never fails in a finite universe

Opening a set one level makes it shallower: rank(∪a) is at most rank(a) − 1. So whatever a is in V₄, ∪a is a set of lower rank and already in V₄. Section 2 checks all sixteen. This is the opposite of pairs and power set, which go one rank up and break every V_n, and it is why the chapter's table has True in this row for every finite universe. An axiom can be needed without ever being the one a small universe lacks: unions are needed because the sets they build, such as the union of an infinite family, are not reachable by the other axioms, not because any V_n refuses them.

Section 4 is the mistake everyone makes once: ∪a is not a. Applied to a set of numbers it would open the numbers, and in set theory numbers are sets, so ∪{1, 2, 3} is a real set, and it is not {1, 2, 3}. Python's `set().union(*a)` is ∪a and `a | b` is a ∪ b, and the two agree where both make sense.

## Po polsku, w skrócie

Aksjomat sumy nie mówi o a ∪ b. Mówi: dla każdego zbioru a istnieje zbiór ∪a, którego elementami są elementy elementów a, czyli to, co wysypie się z członków a po otwarciu każdego o jeden poziom. Suma dwóch zbiorów to przypadek szczególny: a ∪ b = ∪{a, b}, najpierw para, potem aksjomat. Dzięki temu jeden aksjomat daje też sumę nieskończenie wielu zbiorów. W uniwersum skończonym V₄ aksjomat zawsze zachodzi, bo otwarcie zbioru obniża jego rangę; para i zbiór potęgowy podnoszą rangę i psują każde V_n, suma nie. Odbicie lustrzane, przekrój ∩a, wymaga a ≠ ∅: dla a = ∅ warunek „x należy do każdego elementu a" jest spełniony pusto przez wszystko, więc ∩∅ byłby zbiorem wszystkich zbiorów, którego nie ma. Pułapka: ∪a to nie a; ∪{{1, 2}, {3}} = {1, 2, 3}.
