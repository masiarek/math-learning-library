# Power set: the subsets of a set form a set

**Level:** 201 · for anyone reading ∀v₀∃v₁∀v₂(v₂ ∈ v₁ ⇔ ∀v₃(v₃ ∈ v₂ ⇒ v₃ ∈ v₀)) and finding no word "subset" in it

**One line:** The power set axiom hides ⊆ inside a ∀ … ⇒, promises 𝒫(a), the set of all subsets of a, and is the engine of size in the universe: each stage V_{n+1} is 𝒫(V_n), every finite universe lacks the power set of its top rank, and Cantor's theorem says 𝒫(a) is strictly bigger than a even when a is infinite, which is where the real numbers come from.

## The axiom, read aloud

> ∀v₀ ∃v₁ ∀v₂ (v₂ ∈ v₁ ⇔ ∀v₃ (v₃ ∈ v₂ ⇒ v₃ ∈ v₀))

For every set a there is a set b such that z is a member of b exactly when every member of z is a member of a. The inner formula ∀v₃(v₃ ∈ v₂ ⇒ v₃ ∈ v₀) is the definition of z ⊆ a spelled out, since the language has no ⊆ of its own; so b's members are the subsets of a, and b is **the power set** 𝒫(a). Cunningham states it first in English, *for every set A there is a set P that consists of all the sets that are subsets of A*, then as ∀A ∃P ∀x (x ∈ P ↔ ∀y (y ∈ x → y ∈ A)); it is the same formula with letters for the variables and → for ⇒. Cori and Lascar call it the axiom of subsets.

## What it is for

**Counting subsets.** Each member of a is in or out of a subset, independently, so a set of n members has 2ⁿ subsets: section 1 lists them for n up to 3. The subsets of {1, 2, 3} on page 4 of Cunningham are the eight sets ∅, {1}, {2}, {3}, {1, 2}, {1, 3}, {2, 3}, {1, 2, 3}, and 𝒫(A) ∋ X exactly when X ⊆ A.

**Growing the universe.** The stages of this chapter are power sets of each other: V₂ = 𝒫(V₁), V₃ = 𝒫(V₂), V₄ = 𝒫(V₃), checked in section 2, so their sizes go 1, 2, 4, 16, 65 536, 2⁶⁵ ⁵³⁶. The pair axiom adds one rank at a time; the power set axiom adds everything a rank holds at once.

**The real numbers.** A real number in [0, 1] is a sequence of bits, which is a subset of ℕ (the positions of the 1s), so ℝ lives in 𝒫(ω) and a function from ℝ to ℝ in 𝒫(𝒫(ω)). Without this axiom, Zermelo's theory could not prove that the set of real numbers exists.

**Cantor's theorem.** 𝒫(a) is always strictly bigger than a. For finite a that is 2ⁿ > n, section 5; for infinite a it is the diagonal argument, run in [the reading guide's program](../../reading_guides/set_theory/README.md): no map from a onto 𝒫(a) exists. So 𝒫(ω) is uncountable, and 𝒫(𝒫(ω)) is bigger again, and there is no largest set.

## What goes wrong without it

Section 3 counts: of the sixteen sets in V₄, the four of rank at most 2 have their power set in V₄ and the twelve of rank 3 do not, because 𝒫 of a rank-3 set has rank 4. The axiom asks for a set one rank up, as pairs does, and every finite stage fails it. Nor is it a consequence of the other axioms: a universe can satisfy all of them and still be countable (Skolem's observation of 1922), in which case the "power set of ω" it contains is not the real one. What the axiom asserts is the existence of all subsets, including the ones no formula describes, and that is a much stronger claim than it looks.

## Po polsku, w skrócie

Aksjomat zbioru potęgowego mówi: dla każdego zbioru a istnieje zbiór 𝒫(a), którego elementami są dokładnie podzbiory a. W formule nie ma znaku ⊆; zastępuje go ∀v₃(v₃ ∈ v₂ ⇒ v₃ ∈ v₀), czyli „każdy element z jest elementem a", a Python pisze to `z <= a`. Zbiór n-elementowy ma 2ⁿ podzbiorów, bo każdy element jest w podzbiorze albo nie. To silnik wzrostu uniwersum: V₂ = 𝒫(V₁), V₃ = 𝒫(V₂), V₄ = 𝒫(V₃), a rozmiary rosną 1, 2, 4, 16, 65 536. W V₄ brakuje zbiorów potęgowych wszystkich zbiorów rangi 3, więc aksjomat nie zachodzi w żadnym skończonym V_n. Twierdzenie Cantora mówi, że 𝒫(a) jest zawsze ściśle większy od a, także dla a nieskończonego; dlatego 𝒫(ω) jest nieprzeliczalny, a tam mieszkają liczby rzeczywiste.
