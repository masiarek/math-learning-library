# Graphs of equations: intercepts and symmetry

**Level:** 101 · for anyone starting precalculus

**One line:** The graph of an equation is the set of every point whose coordinates make it true, and the rest of the section is that sentence applied: a point is on the graph if it passes the equation, an intercept is a point of the graph with one coordinate 0, and a symmetry is a mirror image that passes the equation too.

## The idea

An equation in x and y, such as y = x² − 4, is a test that each point of the plane passes or fails. (2, 0) passes, since 0 = 4 − 4; (1, −2) fails, since −2 ≠ 1 − 4. The **graph** of the equation is the set of all the points that pass. That is the whole definition, and it is the same idea as the solution set of a [linear equation](../../07_Linear_Systems/linear_equations/README.md): an equation in two unknowns has infinitely many solutions, each a pair (x, y), and plotting them all draws the graph.

The book's section 1.2 has three objectives, and all three are this definition put to work:

1. **Is a point on the graph?** Substitute its coordinates. The equation holds, or it does not.
2. **Intercepts.** The points where the graph meets an axis. A point on the x-axis has y = 0, so to find the x-intercepts, set y = 0 and solve for x; for the y-intercepts, set x = 0 and solve for y.
3. **Symmetry.** A graph is symmetric about the y-axis if the mirror image (−x, y) of every point on it is also on it, and so on for the other mirrors. To test, replace x by −x and see if you get an equivalent equation.

This page follows section 1.2, *Graphs of Equations in Two Variables; Intercepts; Symmetry*, in Michael Sullivan's *Precalculus*.

## Symbol by symbol

| Piece | Say it | What it means |
|---|---|---|
| graph of an equation | | the set of all points (x, y) whose coordinates satisfy it. Not "the drawing": the drawing is a picture of the set. |
| satisfies | "satisfies" | makes the equation true when its coordinates are put in for x and y. |
| x-intercept | "x-intercept" | the x-coordinate of a point where the graph meets the x-axis. A number, not a point: the x-intercepts of y = x² − 4 are −2 and 2. |
| y-intercept | "y-intercept" | the y-coordinate of a point where the graph meets the y-axis. |
| symmetric about the x-axis | | whenever (x, y) is on the graph, so is (x, −y): the lower half is the upper half reflected. |
| symmetric about the y-axis | | whenever (x, y) is on it, so is (−x, y): left and right halves mirror each other. |
| symmetric about the origin | | whenever (x, y) is on it, so is (−x, −y): turning the graph half a turn about O leaves it unchanged. |

A word on the intercepts: Sullivan defines them as numbers, the coordinates, and some other books mean the points. Say which you mean if it matters: "the x-intercept 3" and "the point (3, 0)" are safe either way.

## The three symmetry tests

| Symmetric about | Replace | Example that passes |
|---|---|---|
| the x-axis | y by −y | x = y², since x = (−y)² is the same equation |
| the y-axis | x by −x | y = x² − 4, since (−x)² = x² |
| the origin | x by −x **and** y by −y | y = x³ − x, since −y = −x³ + x is y = x³ − x times −1 |

"Equivalent" allows rearranging: multiplying both sides by −1, as in the origin test above, gives back the same equation, so the test passes. A test fails if a single point on the graph has a mirror image that is not, and the program finds such a witness: (2, 6) is on y = x³ − x, and (−2, 6) is not, so the graph is not symmetric about the y-axis.

Two consequences, both in the program:

- **Any two symmetries force the third.** Reflecting in the x-axis and then in the y-axis is the same as half a turn about the origin, so an equation that passes two tests passes all three. The ellipse x² + 4y² = 16 does.
- **A graph of y = f(x) is almost never symmetric about the x-axis.** If (x, y) and (x, −y) are both on it, one x has two y's, which a function cannot have unless y = 0.

## Questions

**1. Is (1, −3) on the graph of y = x² − 4? Is (−3, 5)? Is (0, 4)?**

<details><summary>Answer</summary>

(1, −3): 1 − 4 = −3, yes. (−3, 5): 9 − 4 = 5, yes. (0, 4): 0 − 4 = −4, not 4, so no. The point (0, −4) is on it.

</details>

**2. Find the intercepts of 4x² + 9y² = 36.**

<details><summary>Answer</summary>

y = 0: 4x² = 36, x² = 9, x-intercepts −3 and 3. x = 0: 9y² = 36, y² = 4, y-intercepts −2 and 2.

</details>

**3. Find the intercepts of y = x² + 1. What does the answer say about the picture?**

<details><summary>Answer</summary>

x = 0 gives the y-intercept 1. y = 0 gives x² = −1, which has no real solution: no x-intercepts. The graph stays above the x-axis; it is a parabola with its lowest point at (0, 1).

</details>

**4. Test y = x⁴ − 2x² for symmetry.**

<details><summary>Answer</summary>

y-axis: (−x)⁴ − 2(−x)² = x⁴ − 2x², the same: symmetric. x-axis: −y = x⁴ − 2x² is a different equation: not. Origin: −y = x⁴ − 2x², not. Only even powers of x means y-axis symmetry.

</details>

**5. Test y = x³ for symmetry.**

<details><summary>Answer</summary>

Origin: −y = (−x)³ = −x³, so y = x³: symmetric. y-axis: y = −x³, different: not. x-axis: −y = x³, different: not.

</details>

**6. A graph is symmetric about the y-axis and (3, −2) is on it. Name another point on it. What if it is symmetric about the origin instead?**

<details><summary>Answer</summary>

y-axis: (−3, −2). Origin: (−3, 2). About the x-axis it would be (3, 2).

</details>

**7. A graph is symmetric about both axes. Must it be symmetric about the origin?**

<details><summary>Answer</summary>

Yes. From (x, y), x-axis symmetry gives (x, −y), and then y-axis symmetry gives (−x, −y), which is origin symmetry.

</details>

**8. Symmetric about the origin: does that mean the graph goes through the origin?**

<details><summary>Answer</summary>

No. xy = 1 is symmetric about the origin, since (−x)(−y) = xy, but (0, 0) fails: 0 ≠ 1. Symmetry says where points come in pairs, not which points are there.

</details>

**9. Why are the x-intercepts found by setting y = 0, and not x = 0?**

<details><summary>Answer</summary>

The x-intercepts are where the graph meets the x-axis, and every point of the x-axis has y = 0. It sounds backwards and is the most common slip in the section.

</details>

**10. Is (0, 0) an x-intercept or a y-intercept of y = x³ − x?**

<details><summary>Answer</summary>

Both: the point is on both axes, so 0 is an x-intercept and also the y-intercept. The x-intercepts are −1, 0 and 1.

</details>

**11. Can the graph of an equation of the form y = (an expression in x) be symmetric about the x-axis?**

<details><summary>Answer</summary>

Only if it is y = 0. Otherwise some x would need two y's, y and −y. That is why x = y², solved for x, is the book's x-axis example.

</details>

**12. The program tested symmetry by comparing F(−x, y) with F(x, y) at a grid of fractions. Why is that trustworthy for these equations?**

<details><summary>Answer</summary>

F(−x, y) − F(x, y) is a polynomial of degree at most 3, and a nonzero polynomial of low degree cannot vanish on that many points of a grid, so agreeing everywhere on the grid means agreeing everywhere. For an equation with square roots or fractions in x, the sample test would need more care.

</details>

## How to practise

1. **Two lines per intercept problem**: "y = 0: …" and "x = 0: …". Writing the substitution first prevents the swap in question 9.
2. **Symmetry: substitute, simplify, compare.** Write the new equation in full, then decide whether it is the old one, maybe times −1.
3. **Guess before testing.** Look at the powers: only even powers of x suggests y-axis symmetry, only even powers of y x-axis symmetry, and all odd powers in both origin symmetry. Then test, because mixed cases fool the guess.
4. **The cards**, especially `trap`.

## Po polsku, w skrócie

Wykres równania to zbiór wszystkich punktów (x, y), których współrzędne spełniają równanie. Cała reszta wynika z tego zdania. Czy punkt leży na wykresie: podstaw i sprawdź. Miejsca przecięcia z osiami: punkt na osi x ma y = 0, więc żeby znaleźć przecięcia z osią x, podstawiamy y = 0 i rozwiązujemy; dla osi y podstawiamy x = 0. Pułapka: brzmi to na odwrót i łatwo się pomylić.

Symetria: wykres jest symetryczny względem osi y, jeśli razem z punktem (x, y) zawiera (−x, y); test to zamiana x na −x i sprawdzenie, czy wychodzi to samo równanie. Względem osi x zamieniamy y na −y, względem początku układu obie zmienne. Dwie symetrie wymuszają trzecią. Symetria względem początku nie znaczy, że wykres przez niego przechodzi (xy = 1). Program rysuje wykresy na siatce tekstowej i sprawdza wszystko dokładnie.
