# The difference law: A ∖ B = A ∩ B′

**Level:** 101 · one law of [the algebra of sets](../../README.md), on its own page

**One line:** Set difference is not a new operation but intersection with a complement, which is why it inherits no law of its own and why every identity about ∖ is proved by rewriting it away.

## The law

| Sets | Logic | Python |
|---|---|---|
| A ∖ B = A ∩ B′ | p ∧ ¬q | `a - b == a & (U - b)` |

## Why it is true

x ∈ A ∖ B means x ∈ A and x ∉ B, which is x ∈ A and x ∈ B′, which is x ∈ A ∩ B′. One definition, read twice. A law of sets is decided one member at a time, so checking it on every subset of a four-element universe, every pattern of membership there is, proves it; the program does that and prints the matching truth table.

## Where it is used, and the trap

Rewrite ∖ as ∩ B′ and the laws above do the rest: (A ∖ B) ∖ C = A ∩ B′ ∩ C′ = A ∖ (B ∪ C), and A ∖ (B ∖ C) = A ∩ (B ∩ C′)′ = A ∩ (B′ ∪ C) = (A ∖ B) ∪ (A ∩ C), two identities that look unlikely until the rewriting makes them routine. Python's `a - b` is this law, and it needs no U, because A ∩ B′ never looks outside A. The trap, found by search on [the parent page](../../README.md#laws-that-look-true-and-are-not): ∖ is neither commutative nor associative.

## Po polsku, w skrócie

Prawo różnicy: A ∖ B to A ∩ B′, więc różnica nie jest nowym działaniem i nie ma własnych praw; każdą tożsamość z ∖ dowodzi się, zamieniając ją na przekrój z dopełnieniem. Python pisze `a - b` i nie potrzebuje U.
